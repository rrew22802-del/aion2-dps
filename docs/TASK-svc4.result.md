# Результат svc4 — 2.7.0

Добавлен учёт видимых игроков по `45 36` и `GET /v1/nearby`. Таблица ограничена 500 строками, записи истекают через 120 секунд без обновления. Существующие известные поля из парсера сохраняются: ID, имя, распознанный класс, а также необязательные server ID и CP. `seenDamage` накапливает урон из уже разобранных боевых пакетов, приписанный этому игроку. Обновление таблицы использует хеш-таблицу и двусвязный список давности: upsert, перестановка, capacity eviction и удаление одной записи имеют O(1); очистка просроченных строк выполняется при API snapshot и ограничена 500 строками. Таблица не выделяет и не клонирует имя на каждом пакете, а API добавляет его из уже имеющихся actor metadata при формировании ответа.

Добавлен `docs/PACKETS-players.md` с подтверждёнными и неизвестными полями. В `src-tauri/tests/fixtures/45-36-town.hex` сохранены 8 коротких payload из town pcapng; тесты проверяют декодирование ID, латинских, кириллических и ханских имён и сопоставление job/class. `45 37` не подтверждён как leave/despawn, поэтому он больше не удаляет участника party и не очищает nearby. Уровень, легион, раса/фракция, координаты, титул, gear score и достоверный despawn остаются неизвестными. API возвращает для неизвестных координат `null` и сортирует по ID; при наличии обеих позиций применяет сортировку по расстоянию.

Версии Cargo, Tauri и приложения обновлены до `2.7.0`; CHANGELOG дополнен. Описание `/v1/nearby` добавлено в `docs/SERVICE-API.md`.

Проверка: Cargo в локальной среде отсутствует, поэтому Rust-тесты и сборка здесь не запускались. Выполнена ручная сверка изменённых Rust-участков и diff; CI должен подтвердить компиляцию и тесты.
